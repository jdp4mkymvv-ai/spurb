# TrendTrack E-commerce — Projet de lancement

Projet structuré de création de boutiques e-commerce basées sur la recherche de produits gagnants (TrendTrack + outils complémentaires), avec des campagnes d'acquisition payante (Meta / TikTok).

## Paramètres du projet

| Paramètre | Valeur |
|---|---|
| Statut juridique | Autoentrepreneur (vente de marchandises, BIC) |
| Budget ads phase de test | 1 500 – 5 000 € sur 2-3 mois |
| Marché cible | Europe francophone (France, Belgique, Suisse) |
| Plateforme boutique | Shopify (voir justification dans `docs/02-boutique-shopify.md`) |
| Outil de recherche produit | TrendTrack (abonnement à prendre — comparatif dans `docs/01-recherche-produits.md`) |

## Stratégie en une phrase

**Une seule boutique d'abord.** On valide un produit gagnant avec des tests ads disciplinés, on scale, et seulement ensuite on duplique le système sur d'autres boutiques. Lancer plusieurs boutiques avant d'avoir un produit validé disperse le budget et multiplie les coûts fixes sans multiplier les chances de succès.

## Structure du projet

```
docs/
  00-roadmap.md              Roadmap par phases avec critères de passage
  01-recherche-produits.md   Framework de sélection produit + process TrendTrack
  02-boutique-shopify.md     Choix plateforme + checklist de lancement boutique
  03-ads-playbook.md         Playbook de test et scaling Meta/TikTok
  04-legal-finances.md       Autoentrepreneur, TVA, unit economics, seuils d'alerte
templates/
  fiche-produit.md           Template de validation d'un produit candidat
tracking/
  produits-testes.csv        Historique des produits testés et verdicts
  budget-ads.csv             Suivi des dépenses ads vs budget
```

## Par où commencer

1. Lire `docs/00-roadmap.md` — c'est le fil conducteur.
2. Faire les actions de la Phase 0 (comptes, abonnements, cadre légal).
3. Remplir une `templates/fiche-produit.md` pour chaque produit candidat avant de dépenser 1 € en ads.
