# Stratégie produit n°1 — Compléments alimentaires pour animaux (décision du 2026-07-20)

Choix du fondateur : compléments animaux en priorité, en démarrant en dropshipping. Le duo confort chien (coussin + tapis) passe en **plan B validé** — il reste disponible immédiatement si les devis compléments déçoivent.

## Pourquoi ce choix tient la route (rappel des données)

- Audit de saturation : 4-5 annonceurs FR seulement ; Woofilab (~530 ads, funnel advertorial) prouve que le marché FR paie 35,90 € en acquisition froide
- Les géants du créneau (Wuffes 2 307 ads US, PetLab Co 570) n'ont pas encore attaqué la France
- Seul cluster avec RÉACHAT : un pot dure 4-8 semaines → LTV élevée, abonnement possible
- Marge marque blanche : 85-90 % (2-5 € le pot, revente 33-36 €)

## Produit héros de lancement

**UN seul produit : complément anti-démangeaisons / apaisement cutané chien** (le best-seller commun de besti.fr ET woofilab.com — validation croisée maximale). Gamme élargie (articulations, digestion, immunité) seulement après validation.

## Séquence de lancement

1. [ ] Devis envoyés (emails prêts dans `outreach/`) : Floralpina, Fulfillment Nutra, Lustrel + inscription Clinivet pour voir le catalogue/remises réelles
2. [ ] Déclaration exploitant secteur alimentation animale (DDPP du département — formulaire gratuit)
3. [ ] Choix de la voie selon devis (critère : marge nette après logistique ≥ 70 % en voie 2/3)
4. [ ] Échantillons + analyse du funnel Woofilab (advertorial) pendant l'essai gratuit 3j TrendTrack Ads
5. [ ] Nom de marque, boutique mono-produit, page advertorial, 5 créas
6. [ ] Protocole de test playbook 03 (150 € max), kill rules inchangées

## Garde-fous réglementaires (non négociables)

- Zéro allégation thérapeutique : « soigne / guérit / traite » interdits → « aide à apaiser », « contribue au confort »
- Étiquetage conforme fourni par le façonnier (règlements UE 767/2009 et 1831/2003)
- Traçabilité : uniquement fabrication française/UE avec certificats
